# 🩸 Blood Bank Management System

A simple Blood Bank Management System developed in **C** as my first university project for the **CSE108: Structured Programming** course. The project demonstrates fundamental programming concepts by managing blood donor records through a menu-driven application.

## 📖 Introduction

The Blood Bank Management System helps organize blood donor information and maintain blood availability records. It provides basic functionalities for managing donor data using user-defined functions and file handling in C.

## ✨ Features

- Add new donor records
- Search donor information
- Update existing records
- Delete donor records
- Display all donor records
- Menu-driven interface

## 🛠️ Technologies Used

- C Programming
- Structures
- User-Defined Functions
- File Handling
